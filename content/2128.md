我们钦定 `dp[i]` 是 i结尾的所有数组 合法子序列的最大长度 的 和
也就是 
$$
\sum_{j = 0}^{i} f(j, i)
$$
其中 f指的就是LCS 最长单调下降子序列

那么对于每一个 `dp[i]` 我们考察他的每一个 f 即可
首先 由于 `[i, i]` 上 只有 `v[i]` 一个 显然合法 也就是 f(i, i) = 1
那 `dp[i]` 可以直接初始化为1
其次 在不考虑 `v[i]` 贡献的前提下 我们起码有 f(i - 1, i) = f(i - 1, i - 1)
f(i - 2, i) = f(i - 2, i - 1) 这样
也就是 虽然以i结尾 但是 `v[i]` 不参与，所以这些f都由 `dp[i - 1]` 提供
因此 `dp[i] += dp[i - 1]` 

最后 我们来考虑`v[i]` 是怎样贡献的
以下我将证明 如果 `v[i - 1] > v[i]`  那么`v[i]` 可以直接被接在f(..., i - 1)后面

如果 `v[i - 1] > v[i]` 那么就有以下几种情况：
- `v[i - 1]` 参与了$\sum_{j = 0}^{i - 1} f(j, i - 1)$ 的构建 那我们只要简单的把 `v[i]` 接到后面就行了
- `v[i - 1]` 没有参与那个的构建 那就是说 `v[i - 2] < v[i - 1]` 不然我们没理由不用更小的 `v[i - 1]` 。既然如此 我们就又可以分为两类：
	- `v[i - 2] > v[i]` 这样我们也是直接接上去就可以了 
	- `v[i - 2] < v[i]` 那我们往回找`v[i - 3]` 根据题目 `max(v[i - 3], v[i - 2]) > v[i - 1]` 然而`v[i - 2] < v[i - 1]` 因此有 `v[i - 3] > v[i - 2] && v[i - 3] > v[i - 1]` 也就是说 这种情况下 其实本来尾接`v[i - 2]`和尾接`v[i - 1]` 是没区别的 提供的最大长度是一样的 那我们直接把`v[i - 3]` 接到`v[i - 1]` 然后尾接`v[i]`即可

因此 上述设定得证。
那我们就只要考虑接上去多多少就行了 其实就是从0到i - 1一共有i条 每一条加1 
`dp[i] += i`

综合起来就是
```cpp
vector<int> dp(n);
dp[0] = 1; // v[0]自己就是
for (int i = 1; i < n; i++)
{
	dp[i] = 1 + dp[i - 1];
	if (v[i - 1] > v[i]) dp[i] += i;
}

cout << accumulate(all(dp), 0ll);
```
